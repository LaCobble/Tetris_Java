## [1.0.0] - 2023-06-06

First version, as delivered for the school assignment.

### Added

- Tetris game in JavaFX: random tetrominoes, movement, rotation, hard drop, line clearing, score, pause and game over.
- Main menu with Options (difficulty: Easy, Medium, Hard, GodMode), Score (top-3 podium) and Credits pages.
- Interfaces for the object model (board, cell, point, tetromino, game).

### Changed

- 2023-06-06: removed the earlier `dev/` and `prod/` drafts, keeping the final JavaFX version.
